# AI-ML-EV-Battery-Predictive-Maintenance
AI/ML-based EV battery monitoring system using ESP32 and sensors to track voltage, current, and temperature in real time. Machine learning detects abnormal conditions and battery degradation, enabling predictive maintenance, alerts, and battery health monitoring through a user-friendly dashboard.
# AI/ML Based Predictive Maintenance of EV Battery

 Overview

This project presents an AI/ML-based system for monitoring and predictive maintenance of lithium-ion batteries used in Electric Vehicle applications.

The system continuously monitors battery voltage, current, and temperature using sensors connected to an ESP32 microcontroller. The collected data is analyzed using Machine Learning techniques to identify abnormal operating conditions and early signs of battery degradation.

 Hardware Components

- ESP32
- Li-ion Battery
- INA219 Current Sensor
- DS18B20 Temperature Sensor
- Voltage Sensor
- TP4056 Charging Module

 Features

- Real-time battery monitoring
- Voltage, current, and temperature measurement
- AI/ML-based battery condition analysis
- Abnormal condition detection
- Predictive maintenance alerts
- Battery health monitoring
- Dashboard visualization

 System Workflow

Sensors → ESP32 → Data Collection → AI/ML Model → Battery Health Analysis → Dashboard & Alerts

Objective

To develop a cost-effective AI/ML-based system capable of detecting abnormal battery behavior and predicting early signs of battery degradation.

Technologies Used

- Python

Future Scope
